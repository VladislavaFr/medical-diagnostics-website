# 🏥 Medical Diagnostics Website

Веб-приложение для компании медицинской диагностики с возможностью онлайн-записи пациентов, управления услугами и администрирования контента.

## 📌 Описание проекта

Проект представляет собой сайт медицинской диагностической компании, который решает задачи:
- онлайн-записи пациентов на прием  
- управления медицинскими услугами  
- хранения информации о пользователях и врачах  
- администрирования контента без участия разработчика  

Система включает пользовательский интерфейс и административную панель Django.

## 🚀 Функционал

### Пользовательская часть:
- Главная страница с описанием компании  
- Страница "О компании"  
- Просмотр списка медицинских услуг  
- Регистрация и авторизация пользователей  
- Личный кабинет:
  - запись на прием  
  - просмотр истории записей  

### Административная часть:
- Управление пользователями  
- Управление врачами  
- Управление услугами  
- Управление записями на прием  
- Управление контентом сайта  

## 🛠 Технологии

- Backend: Django 4.2  
- Frontend: HTML, CSS, Bootstrap  
- База данных: PostgreSQL  
- Кэширование: Redis  
- Контейнеризация: Docker, Docker Compose  
- CI/CD: GitHub Actions  
- Тестирование: pytest / Django test framework

## ⚙️ Установка и запуск

git clone <your-repo-url>
cd project

python -m venv venv
source venv/bin/activate

pip install -r backend/requirements.txt

Создайте файл .env и заполните переменные окружения

cd backend
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

## 🐳 Docker

docker compose up --build -d

## 🧪 Тесты

python manage.py test
